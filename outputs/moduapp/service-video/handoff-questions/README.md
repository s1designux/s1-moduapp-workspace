# 영상 탭 확인 질문 화면 — 다른 계정에서 다시 만들기

`video-questions.html` 한 파일에 질문 17개와 참고 그림 24장이 모두 들어 있다(그림은 파일 안에 넣어 둠).

## 다른 계정에서 아티팩트로 만들 때
1. Claude(claude.ai 또는 Claude Code)에 `video-questions.html`을 올린다.
2. 아래 글을 그대로 붙여 넣는다.

> 첨부한 HTML 파일을 내용·디자인을 바꾸지 말고 그대로 아티팩트로 올려줘.
> 담당자가 답을 저장할 수 있게 capabilities 는 `db: {}` 와 `user: {scopes: ["profile"]}` 로 선언해줘.
> 답은 `answers` 모음에 질문 번호(a1~a8, b1~b9)별로 저장돼. 나중에 내가 "답 정리해줘" 하면 그걸 읽어서 표로 정리해줘.

3. 올린 뒤 공유 메뉴에서 담당자를 '참여자' 이상으로 추가한다.

## 알아둘 것
- 그 계정에서 "답 저장" 기능을 못 쓰면, 질문과 그림은 보이고 답 칸만 저장이 안 된다. 그때는 담당자가 메모로 답을 따로 보내야 한다.
- 브라우저에서 파일을 그냥 열어도 질문·그림은 다 보인다(답 저장만 안 됨).
- 원본: river 계정 아티팩트(2026-10-21). 질문 근거는 `../video-v2-open-decisions.md`, `../video-v2-screen-analysis.json`의 확인 필요 항목.
