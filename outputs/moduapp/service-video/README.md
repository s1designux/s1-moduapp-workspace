# 모두앱 영상 탭 — NVR 기준 분석 꾸러미 (입구)

다른 세션·프로젝트가 이 분석을 가져다 쓸 때 **이 파일부터** 읽는다. (정리: 2026-10-21)

## 이 자료는 무엇인가
- 모두앱 영상 탭 **신규 기준** 화면(2026-10 Figma "클라우드영상시스템 › 모두앱 영상")을 분석한 것이다.
- 이 화면은 **NVR(녹화기) 연동 기준**으로만 만들어졌다. 클라우드영상시스템 대응 내용은 없다.
  - 클라우드 쪽에서는 이 자료를 "이어받을 뼈대와 작은 사양"으로 읽는다.
  - NVR에만 해당하는 것은 `scope` 꼬리표로 구분해 두었다. 아래 "NVR 전용" 참고.
- 화면 270개, 부품 20개, 부품 묶음 12개, 맥락(사용자가 하려는 일) 15개, 그림 54장으로 되어 있다.
- **레거시 주의**: `legacy/moduapp/service-video/`의 예전(현행) 화면 분석은 기준이 아니다. 섞어 쓰지 않는다.

## 꼬리표의 뜻
- `scope`(쓰임 범위)
  - **공통 뼈대**: 영상 탭이면 어디서나 쓰는 구조·부품
  - **NVR 기준 기능**: 기능은 비슷해도 NVR이 주는 데이터에 기대는 것
  - **SVMS 고객 전용**: 기업용 SVMS 고객에게만 보임
  - **PTZ 카메라 전용**: 방향을 돌릴 수 있는 카메라에만 보임
- `confidence`(확신)
  - **그림 확인**: Figma 스크린샷으로 직접 봄
  - **데이터로 셈**: 분석 기록·Figma 부품 이름으로 셌고 그림으로 다 보지는 않음
  - **추정**: 여러 화면을 견주어 찾은 해석. 규칙 6개가 여기에 해당한다. 확정 사양이 아니다.

## NVR 전용으로 보아야 할 것
- NVR 2차 로그인
- 더보기 › 상세 설정(= NVR 웹뷰어 설정)
- 움직임 감지 탭(NVR 움직임 이벤트)
- PTZ 조종판·제어 속도
- SVMS 레이아웃 리스트·이벤트 목록
- 영상 칸 상태 4가지의 정의(NVR 연결 기준)

## 다루지 않은 것
- 색·글자 크기·모서리·그림자 같은 디자인 시스템 값은 재지 않았다.
- 클라우드 대응, 와이어프레임은 이 워크스페이스에서 하지 않는다. 결정: river 2026-10-14, `docs/context/video-tab-baseline.md`
- 지난 분석의 확인 필요 96건·이름 불일치 52건은 `video-v2-screen-analysis.json`의 `needs_review`·`mismatches`에 그대로 있다.
