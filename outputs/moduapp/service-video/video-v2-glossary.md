## 대표 상태 8가지

- **기본** — 아무것도 안 덮인 화면
- **버튼 뜬 상태(딤)** — 딤이 떠 있음
- **바텀시트 열림** — 세로 시트
- **가운데 팝업** — 가로 팝업
- **오른쪽 패널** — 가로 패널
- **토스트** — 토스트가 뜬 순간
- **영상 안 나옴** — 수신 불량·카메라 없음·신호 없음
- **빈 화면** — 목록에 기록이 없음

## 맥락 15가지

- **영상 보기** — 영상 탭에 들어와 지금 현장 카메라를 본다
- **조작 버튼 꺼내기** — 영상을 한 번 눌러 숨어 있던 조작 버튼을 꺼낸다
- **영상이 안 나올 때** — 영상이 안 나올 때 왜 그런지 알아챈다
- **크게 보기(핀치 확대)** — 영상 한 부분을 손가락으로 크게 본다
- **화면 나누기(분할 수)** — 한 화면에 카메라를 몇 대 볼지 고른다
- **화면 비율 바꾸기** — 영상을 원래 비율로 볼지, 칸에 꽉 채울지 바꾼다
- **다음 카메라 묶음 넘기기** — 분할 칸보다 카메라가 많을 때 다음 묶음으로 넘긴다
- **다른 카메라 고르기** — 지금 보는 카메라를 다른 카메라로 바꾼다
- **카메라 묶음 고르기(SVMS)** — (SVMS 고객) 미리 묶어 둔 카메라 묶음을 고른다
- **지난 영상 날짜·시간 찾기** — (녹화) 보고 싶은 날짜·시각으로 이동한다
- **재생·배속 조절** — (녹화) 재생·멈춤·빨리감기·30초 이동을 한다
- **움직임·이벤트 찾아보기** — (녹화) 움직임·이벤트가 있던 시점을 찾아 본다
- **화면 저장(캡쳐)** — 지금 화면을 사진으로 저장한다
- **카메라 방향 돌리기(PTZ)** — (PTZ 카메라) 카메라 방향과 확대를 직접 조종한다
- **기타 메뉴(더보기)** — 상세 설정·원격지원요청·방문점검신청으로 간다
