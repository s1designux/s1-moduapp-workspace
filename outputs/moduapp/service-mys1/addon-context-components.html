맥락을 가로지르는 규칙

  1. 신청도 해지도 '바로 반영'이 아니라 '요청 접수'
    고르기 화면 안내는 '전화 상담을 통해 자세히 안내', 상세 처리상태는 '고객센터에 전달하였습니다', 메인은 '반영 중'. 앱은 요청서를 넣는 창구 역할만 한다. 추정(세 화면 글을 견주어 찾음)
  2. 누가·어느 계약처인지는 앱이 미리 채운다
    계약처명·이름·휴대전화번호는 회색 읽기 전용 칸. 사용자가 적는 것은 '무엇을' 고르기와 '내용' 한 칸뿐. 그림 확인
  3. 서비스는 늘 사업 영역별로 묶는다
    메인·해지·신청 모두 시스템 경비 / 영상 / 출입 관리 / 생활안심 제목 아래에 서비스를 놓는다. 그림 확인
  4. 아래 버튼은 보조(흰) 왼쪽 + 주(파랑) 오른쪽, 화면 맨 아래 고정
    신청 이력·신규 신청 / 취소·다음 / 취소·확인 / 취소·해지 신청. 하나일 때(목록)는 파랑 한 개. 그림 확인
  5. 적는 칸은 하나, 최소 10자 · 최대 120자
    신청·해지 모두 같은 내용 상자와 같은 자리표시 글. 그림 확인

부가서비스 해지 신청
5.5 부가서비스_7 해지 신청		이용 중인 부가서비스 중 해지할 것을 체크하고, 내용(최소 10자·최대 120자)을 적어 '해지 신청'을 누른다. 계약처명과 신청자 정보는 미리 채워져 있고 고칠 수 없다(회색 칸).
부가서비스 신규 신청 1단계 (서비스 고르기)
5.5 부가서비스_8 신규 신청(상품 선택)		맨 위 안내 '부가서비스를 선택하신 후 신청해 주시면 전화 상담을 통해 자세히 안내 드립니다.' 아래로 4개 영역(시스템 경비 3 · 영상 4 · 출입 관리 6 · 생활안심 1) 14개 서비스를 체크 카드로 고른다. 카드마다 이름 + 설명 2~3줄. 고른 카드는 하늘색 바탕 + 파란 체크. 아래 '취소 · 다음'.
부가서비스 신규 신청 2단계 (내용 적기)
5.5 부가서비스_9 신규 신청(정보 입력)		고른 서비스가 '부가서비스' 칸에 읽기 전용으로 모여 보이고(예시 '영상기기 관리, 식당관리'), 내용(최소 10자·최대 120자)을 적어 '확인'을 누른다. 계약처명·신청자 정보는 해지 신청과 같은 모양.
