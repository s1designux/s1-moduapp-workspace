# 프로젝트 개요 — S1 모두앱 UX Subagent Workspace

## 이 프로젝트는 무엇인가

Claude Subagent를 활용해 모두앱 UX 분석 담당자 팀을 만드는 실험 프로젝트입니다.

기존에는 UX 디자이너가 직접 화면을 보고 분석하고, 디자인 시스템을 대입해보고, 검수 기준을 적용하는 작업을 혼자 했습니다.
이 프로젝트에서는 각 단계를 담당하는 AI 담당자(Subagent)를 만들어, 반복적인 분석과 정리 작업을 체계화합니다.

`s1-mobility-uvis-workspace`(이동체관제)에서 검증한 방법론을 **모두앱(B2C/B2B 모바일 앱)**에 그대로 적용한 형제 워크스페이스입니다.

---

## 현재 범위

**모두앱(moduapp)**만 대상으로 합니다.

모두앱은 관제(operator) 화면이 아니라, 일반 사용자가 직접 사용하는 모바일 앱입니다.
따라서 정보 밀도보다는 **명료함, 행동 유도(CTA), 화면 간 흐름, 상태 표현**을 중심으로 분석합니다.

---

## 현재 단계

담당자를 정의하고, 기존 화면 분석을 시작하는 단계입니다.

1. **S0 완료** — 워크스페이스 세팅, 담당자 정의, 기준표 초안 작성
2. **A1 진행 예정** — 모두앱 화면 자료 입수 후 화면 분석 시작

---

## 장기 방향

지금은 Claude Subagent로 시작하지만, 나중에는 더 체계적인 자동화 도구로 발전시킬 계획입니다.

- 현재: Claude에게 직접 담당자를 지정해 요청하는 방식
- 중기: 분석 결과가 자동으로 JSON 파일로 저장되고 대시보드에 반영되는 방식
- 장기: **LangGraph** 같은 업무 프로세스 자동화 도구로 전체 흐름을 자동화

이를 위해 모든 담당자의 입력/출력/판단 기준을 명확하게 정의했습니다.

---

## 원칙

- **비개발자가 이해하고 수정할 수 있어야 합니다.** → Markdown, JSON, HTML 중심
- **담당자 이름은 짧고 부르기 쉬워야 합니다.** → ui-reader, ds-mapper, moduapp-reader 등
- **불확실한 것은 추측하지 않습니다.** → needs-review로 표시
- **산출물은 항상 구조화된 형식으로 저장합니다.** → JSON Schema 기준
