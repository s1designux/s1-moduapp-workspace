모두앱(MoDU APP)은 에스원의 **출입관리·영상관리·사용자 권한관리 등 다중 서비스를 하나의 앱에서 관리/모니터링**하는 통합 허브 애플리케이션이다. 단일 도메인이 아니라 여러 하위 서비스를 한 앱 셸 안에 묶는 구조.

**Why:** 사용자가 2026-05-26에 명시. 초기 세팅의 기준이었던 mobility(UVIS, 이동체관제)는 단일 도메인 관제 서비스라, 모두앱과는 서비스 성격이 전혀 다르다고 강조함. 따라서 mobility의 "화면 단위 평면 수집" 방식을 그대로 쓰면 안 되고, 모두앱은 앱 셸/공통 + 서비스별 + 횡단(권한·연계) 의 다층 메타데이터 모델이 필요하다.

**How to apply:** 모두앱 분석/제안 시 항상 다층(레이어) 구조를 전제로 한다 — ① 앱 셸·공통(로그인/네비/통합 홈/알림/설정), ② 서비스 모듈별, ③ 횡단(역할·권한). IA(서비스맵) 파악을 화면 분석보다 먼저 한다(top-down). 작업 워크스페이스 (이 프로젝트 폴더). Figma file 〔따로 보관: 피그마파일-2〕 (MoDU-APP-20240327-최종).

**담당자(배지숙) 확정 사실 (2026-05-27):**
- 핵심 '서비스'는 4종: 경비(시스템경비)·영상·카드·마이에스원(계약/청구/입금). 홈·통합계정·공통·설정=앱셸, 고객센터=지원영역. ('9개 서비스'는 서비스가 아니라 보드 섹션 단위였음)
- 사용자는 전원 관리자(마스터관리자/일반관리자). 일반 end-user 없음.
- 로그인 = 아이디(ID/PW) + 휴대폰(PASS). 소셜 없음. 간편번호/지문/FACE는 로그인이 아니라 중요기능 추가인증(원격 경비/해제 등).
- 서비스 권한 종류: 경비/영상/카드/계약/클라우드매니저 + 초대/현황관리. 최초 계약담당자=최초 마스터관리자, 마스터가 초대→권한지정→승인.
