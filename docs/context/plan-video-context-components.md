# 계획 — 영상 탭: 맥락별 부품 조합 상세 분석

- 상태: **완료** (river 요청·OK 2026-10-21, 완료 2026-10-21)
- 앞 단계: [화면 유형별 부품 분석](plan-video-screen-type-components.md) 결과를 바탕으로 한다.

## 목표
사용자가 하려는 일(맥락)마다 어떤 부품 조합을 어디에 어떻게 쓰는지, 같은 일인데 다르게 만든 곳은 어디인지 정리한다.

## 지금까지
- 270화면을 맥락 15개(영상 보기·조작 버튼 꺼내기·영상 안 나옴·핀치 확대·화면 나누기·비율·페이지 넘김·카메라 고르기·SVMS 묶음·날짜·재생·이벤트·캡쳐·PTZ·더보기)에 하나씩 나눔.
- 맥락마다 들어오기/나가기·부품 묶음·세로/가로 자리·뜨는 창·결정 버튼·다르게 만든 곳을 정리. 결과: `outputs/moduapp/service-video/video-v2-context-components.json/html`
- 맥락을 가로지르는 규칙 6개와 다르게 만든 곳 23개를 모아 둠. 흐름 그림 54장(앞 단계 23장 + 이번 31장)을 사본 파일에서 찍어 넣음.

## 그림으로 확인해 바로잡은 것
- 토스트 자리: 화면 설명에는 "영상 칸 위/영상 가운데"로 달리 적혀 있었지만, 그림으로 보면 세로·가로 모두 영상 아래 가운데로 같다. 다르게 만든 곳에서 뺌.
- iOS 녹화 가로 카메라 목록 패널은 탭 없이 제목만 있다(안드로이드는 "카메라 목록 | 움직임 감지" 탭). 그림으로 확인함.
- 레이아웃 리스트·PTZ 속도 창은 결정 버튼 없이 체크로 바로 바뀐다. 그림으로 확인함.
